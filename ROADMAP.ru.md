# Дорожная карта WARP

Стадия: 0.4.0

Этапы идут по порядку: `[x]` — сделано, `[ ]` — в планах. Текущий этап — первый незавершённый.

Дизайн репозиториев и узлов: [docs/NODES.ru.md](docs/NODES.ru.md).

## Базовый менеджер пакетов
- [x] Установка, удаление, список и информация о пакетах
- [x] Версионное локальное хранилище с мгновенным откатом
- [x] Поиск по доступным пакетам
- [x] Сборка архивов `.warp` (`warp pack`)

## Модель доверия
- [x] Доверие только закреплённому ключу Ed25519
- [x] Подписанный индекс, скачиваемый вместе с подписью с одного зеркала
- [x] Проверка sha256 каждого архива и дельты по индексу
- [x] Генерация ключей и подпись (`warp keygen`, `warp sign`)

## Репозитории и обновления
- [x] Несколько репозиториев с закреплёнными ключами
- [x] `warp upgrade` для установленных пакетов
- [x] Бинарные дельта-обновления (формат WARPDLT1)
- [x] Зависимости в подписанном индексе (закреплены по версии)
- [x] Волонтёрская раздача пакетов (`warp seed`, `warp volunteer`) с квотой диска и месячным лимитом отдачи

## Проверка на дистрибутивах
- [x] Тесты дельт и e2e-тест install → upgrade → rollback
- [x] CI на K1OS, Alpine, AlmaLinux, Arch, Artix, Devuan, Fedora, Ubuntu, Void и Void musl

## Защита от отката
- [ ] Номер версии и срок годности у индекса
- [ ] Клиент отказывается от индекса старше уже виденного или просроченного

## Режим репозитория
- [ ] `warp repo init` и `warp publish` вместо внешнего скрипта
- [ ] Раздельные ключи: корневой (офлайн), индекса и онлайн

## Режим узла
- [ ] Сертификаты узлов со сроком годности, подписанные репозиторием
- [ ] Подключение узла по согласию обеих сторон и синхронизация всех пакетов или их части
- [ ] Автоматическое продление, проверка доступности и отзыв узлов
- [ ] Клиент качает с узлов и переключается при сбоях
- [ ] Делегирование пространств имён узлам (по необходимости)
